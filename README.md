# English Wordlists — BSUIR

Тренажёр английских слов по пособию «Topical Issues Through Communication»
(Н. Г. Касперович и др., БГУИР, 2022). 13 уроков, 767 слов из раздела Wordlist (стр. 210–219).

Папка самостоятельная: внутри только материалы учебника и код тренажёра,
ничего личного — её можно целиком отдавать однокурсникам.

## Что открывать

| Файл | Что это |
|---|---|
| `index.html` | Готовый тренажёр. Один файл, открывается двойным кликом в любом браузере, интернет не нужен |
| `wordlists.md` | Все 13 словарей текстом: английский — русский |
| `lesson-03-standalone.html` | Первая версия — только Lesson 3, отдельным файлом |
| `lesson3-vocabulary.md` | Словарь Lesson 3 текстом |

## Режимы тренажёра

- **Уроки** — все 13 уроков с прогрессом по каждому
- **Карточки** — переворот кликом или пробелом, листание стрелками, озвучка
- **Заучивание** — выбор из 4 вариантов с мгновенной проверкой
- **Письмо** — ввод перевода
- **Подбор** — игра на время: собрать 6 пар
- **Тест** — написание или выбор 1 из 4, RU→EN или EN→RU, 10/20/все вопросы, разбор ошибок в конце
- **Список** — весь словарь урока с поиском

## Прогресс

Регистрации и входа нет: страница открывается сразу. Прогресс («выучено» и «трудные ★») хранится
в `localStorage` браузера, отдельно по каждому уроку. У каждого человека и на каждом устройстве
он свой — сервера нет, ничего никуда не отправляется.

Очистка данных сайта в браузере сотрёт прогресс, поэтому время от времени сохраняйте файл.

## Файл прогресса

Кнопка **Прогресс · файл** в панели → **Сохранить файл** — скачивается `progress-дата.json`.
На другом устройстве: та же кнопка → **Загрузить файл**. Загрузка объединяет файл с текущим
прогрессом и ничего не затирает.

Если браузер не даёт скачать файл, рядом появляется текст файла с кнопкой «Скопировать текст»,
а загрузить можно через «или вставить текст».

Формат файла:

```json
{
  "app": "bsuir-english-wordlists",
  "version": 2,
  "exported": "2026-10-03T08:35:31.676Z",
  "progress": {
    "known": { "3007": 1, "3012": 1 },
    "hard":  { "3021": 1 }
  }
}
```

Ключи в `known` и `hard` — это id слова: `номер урока × 1000 + позиция в списке урока`.
Например `3007` — восьмое слово третьего урока. Файлы старой версии с профилями (поле `profile`)
тоже загружаются.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (публичный) и загрузите в него содержимое этой папки —
   достаточно одного `index.html`, но лучше всё, чтобы словари можно было править.
2. Repo → **Settings** → **Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → **Save**.
3. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

`index.html` лежит в корне, поэтому откроется сразу. Внешних запросов страница не делает
(только шрифты Google Fonts), сборка и зависимости не нужны.

## Как добавить или поправить слова

1. Отредактируйте нужный файл в `data/` — формат `["english", "русский", "часть речи"]`.
2. Пересоберите:

```bash
python3 build.py
```

`index.html` собирается из `app-template.html` (вёрстка и логика) и всех `data/lesson-*.json`.
Новый урок — новый файл `data/lesson-14.json` того же формата.
